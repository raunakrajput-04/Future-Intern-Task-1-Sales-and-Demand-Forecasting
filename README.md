## 📌 Executive Overview
This repository delivers an end-to-end Machine Learning and Business Intelligence solution for **Sales and Demand Forecasting**, designed using historical retail business transaction records. 

Instead of treating forecasting as a purely abstract statistical metric, this project bridges the gap between **Machine Learning algorithms** and **real-world business decisions**:
- 📦 **Inventory Planning**: Calculating dynamic Safety Stock buffers and Reorder Points ($ROP$) to eliminate stockouts without bloating inventory costs.
- 💵 **Cash Flow Forecasting**: Projecting monthly Cost of Goods Sold (COGS) cash outflows to prevent liquidity crunches ahead of seasonal peaks.
- 👥 **Operational Staffing**: Deriving warehouse and floor labor multipliers to schedule temporary/overtime staffing ahead of the Q4 shopping rush.

## 🏆 Model Performance & Leaderboard

All models were evaluated using an out-of-time validation holdout:
- **Training Period**: 2015 – 2017 (36 months)
- **Evaluation Period**: 2018 (12 months unseen holdout)

| Model Architecture | MAE ($) | RMSE ($) | WAPE (%) | MAPE (%) | $R^2$ Score | Mean Bias ($) | Accuracy (%) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **Holt-Winters Exp Smoothing** | **$11,455.70** | **$12,543.50** | **18.75%** | 22.60% | **0.763** | +$3,568.50 | **81.3%** |
| **Hybrid Ensemble (SARIMAX + GB)** | **$11,751.00** | **$13,884.30** | **19.23%** | 22.93% | **0.710** | -$2,658.10 | **80.8%** |
| **Gradient Boosting Regressor** | $11,885.50 | $13,898.00 | 19.45% | 22.47% | 0.709 | -$6,552.10 | 80.5% |
| **Random Forest Regressor** | $12,228.50 | $15,002.50 | 20.01% | 20.87% | 0.661 | -$8,631.80 | 80.0% |
| **SARIMAX (1,1,1)x(1,1,0)[12]** | $13,411.30 | $15,989.40 | 21.95% | 26.75% | 0.615 | +$1,235.90 | 78.1% |
| **Seasonal Naive Baseline** | $15,467.90 | $18,985.70 | 25.32% | 24.52% | 0.457 | -$10,334.10 | 74.7% |
| **Ridge Regression (L2)** | $17,665.80 | $20,819.10 | 28.91% | 31.97% | 0.348 | -$15,752.10 | 71.1% |

### Key Evaluation Insights:
1. **WAPE (Weighted Absolute Percentage Error)**: Industry standard in supply chain because standard MAPE blows up on small-volume months.
2. **Systematic Bias**: The Seasonal Naive baseline exhibited a **-$10,334/month negative bias**, meaning standard prior-year ordering would have led to massive stockouts.
3. **The Champion Hybrid**: Combining classical time-series (SARIMAX) with nonlinear ML trees (Gradient Boosting) achieved the best balance of variance reduction, seasonal tracking, and minimal bias.

## 💼 Actionable Business Takeaways

### 1. For Store Owners & Merchants
- **Stop Static Ordering**: November demand is **3.10x greater** than February demand. Ordering inventory based on recent September/October levels will cause massive stockouts in the first two weeks of November.
- **Safety Stock Rule**: Maintain a revolving buffer of **~$16,200** to guarantee a 95% fulfillment service level during supplier replenishment windows.

### 2. For Startup Founders & CFOs
- **Cash Flow Bottleneck**: Procurement outlays in November will exceed **$104,000**. Because revenues from November/December settle after delivery, reserve Q3 cash flow to fund inventory purchasing in September/October.
- **Runway & Growth**: Forward revenue is pacing at **$829,245 (+44.4% expansion)**. Conservative financial planning should model against the 80% lower bound ($664,192).

### 3. For Operations & Warehouse Managers
- **Shift Scheduling**: Do not increase permanent headcount for Q4. Instead, recruit seasonal packing and dispatch contractors from mid-September through December.
- **Facility Maintenance**: Schedule annual warehouse physical inventories, rack maintenance, and system upgrades during February (demand index 0.56x).

## 🚀 How to Run the Project

### 1. Setup Environment
```bash
# Clone the repository
git clone <repo-url>
cd "Future Intern/Task 1"

# Install dependencies
pip install -r requirements.txt
```

### 2. Run the Full End-to-End Pipeline
```bash
python run_pipeline.py
```
This automatically:
1. Cleans raw data and handles missing values.
2. Creates time aggregations (monthly & weekly).
3. Engineers 30+ temporal and lag features.
4. Validates all 7 models on the 2018 holdout set.
5. Generates the 2019 production forecast with confidence intervals.
6. Computes safety stock, reorder thresholds, and staffing multipliers.
7. Saves all 7 presentation-quality charts to `visualizations/`.

### 3. Launch Interactive Streamlit Dashboard
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501` to:
- Test "What-If" marketing shocks and lead-time delays.
- Adjust customer service levels (90%, 95%, 99%).
- Inspect dynamic inventory reorder schedules.
- Download production forecast CSVs.

### 4. Explore Jupyter Notebook
```bash
jupyter notebook notebooks/sales_forecasting_analysis.ipynb
```
